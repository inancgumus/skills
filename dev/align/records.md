# Records

Use the repo's own word list and decision records when they exist. Otherwise use `words.md` and `decisions.md`, created only when there is something to add. Ask first.

## Add a word

Only for a term specific to this project. Define what it is, and list words to avoid.

## Record a decision

Only when it is hard to reverse, would surprise a future reader, and came from a real trade-off. One paragraph: context, decision, reason.

## Record a rejected idea

One entry per idea, with the lasting reason and who asked. Skip what is already built, and reasons like "too busy".
