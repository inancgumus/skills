# Init

Read these three files in full before you do any other work. This is a MUST.

- `~/.agents/AGENTS.md`
- `~/.agents/docs/design.md`
- `~/.agents/docs/learnings.md`

Read each file to its end. Do not skim, and do not read a part of a file.

After you read all three files, state that you read them, and follow their rules for the rest of the session.
